前走車 発進通知・接近警告 WEBアプリ（YOLO ONNX版）

Transformers.js は使わず、ONNX Runtime Web で YOLOv8n を直接読み込みます。
前方中央の車・トラック・バス・バイクを優先追跡し、近すぎると警告音、停止中に前車が動くと通知音を鳴らします。

標準
動きが重い場合は「最軽量」→「推論間隔を長く」→「検出信頼度を少し下げる」の順で調整してください。
画面中央を切り出して拡大推論します。前走車がモデルに大きく映り、検出率が上がります。画面端の車を検出したい場合はオフにしてください。
調整メモを開く
  • 重くてカクつく: 画質を「最軽量 320×180」にして、推論間隔を 900〜1500ms に上げます。
  • 前の車を見つけにくい: 「中央ズーム推論」をオンのまま、検出信頼度を 0.35 から 0.25〜0.30 へ少し下げます。下げすぎると誤検出が増えます。
  • 誤検出が多い: 検出信頼度を 0.45〜0.60 に上げます。NMS IoU は基本 0.45 のままで大丈夫です。
  • 接近警告が鳴りすぎる: 接近警告しきい値を 0.30〜0.40 に上げます。鳴らない場合は 0.20〜0.27 に下げます。
  • 発進通知が鳴りにくい: 発進通知しきい値を 0.08〜0.10 に下げます。誤通知が多い場合は 0.14〜0.18 に上げます。
  • おすすめ開始設定: 画質「標準 1280×720」、中央ズーム推論オン、検出信頼度 0.35、NMS IoU 0.45、推論間隔 700ms（backend が webgpu なら 400ms）から試してください。
